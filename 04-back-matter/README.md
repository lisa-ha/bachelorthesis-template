# Back Matter

This folder holds all content after your conclusion, like the bibliography, additional content in the appendix and the thesis statement.

* [Bibliography](Bibliography.tex) -- the main bibliography listing all cited references.
* [ExampleAppendix](ExampleAppendix.tex) -- an example appendix chapter.

Only relevant for Bachelor's or Master's theses:
* [StatementThesis](StatementThesis.tex) -- the official thesis statement to be signed.

Only relevant for PhD thesis:
* [CurriculumVitae](CurriculumVitae.tex) -- optional CV.
* [PaperOne](PaperOne.tex) -- example appendix chapter on how to include papers in cumulative dissertations.
* [StatementThesisPhD](StatementThesisPhD.tex) -- the official thesis statement to be signed.

Make sure to double-check the current rules and regulations and adjust the thesis statement and the AI declaration accordingly.
