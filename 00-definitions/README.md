# Definitions

This is the place for central definitions like personal information, acronyms, special hyphenation.

* [Acronyms.tex](Acronyms.tex) -- contains a list of acronyms
* [Hyphenation.tex](Hyphenation.tex) -- custom rules if LaTeX screws up hyphenation
* [PersonalInfo.tex](PersonalInfo.tex) -- must be adjusted by you

## How to use

Adjust all the `\meta<X>` and `\my<X>` variables in [PersonalInfo.tex](./PersonalInfo.tex),
such as your name and title of your thesis.
